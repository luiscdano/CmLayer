Proyectos

Soluciones y plataformas desarrolladas para construir sistemas digitales seguros, escalables e inteligentes.

En esta sección presento algunos de los proyectos tecnológicos que he desarrollado o estoy construyendo como parte de mi trayectoria en ingeniería de software.

Mi trabajo se enfoca en el desarrollo de plataformas web, arquitecturas backend robustas, automatización DevOps y exploración de nuevas tecnologías como inteligencia artificial y sistemas financieros digitales.

Cada proyecto refleja un enfoque práctico orientado a resolver problemas reales mediante software bien estructurado, escalable y alineado con buenas prácticas de ingeniería.

Además de proyectos en producción, también incluyo iniciativas tecnológicas en desarrollo que forman parte de mi visión de construir soluciones modernas para empresas, startups y plataformas digitales.

Proyectos actuales & finalizados

La Casita de Yeya

Sistema web desarrollado para el restaurante La Casita de Yeya que permite mostrar su menú, información del negocio y presencia digital profesional. El proyecto fue diseñado con una estructura ligera y escalable orientada a pequeñas empresas del sector gastronómico.

Categoría: Desarrollo Web Estado: Completado

Rol: Desarrollo full-stack, diseño de base de datos y despliegue del sitio web.

Enlaces: http://lacasitadeyeya.com.do/ Repositorio: https://github.com/luiscdano/LaCasitaDeYeya

Dr. Katherine C - Pediatrics

Plataforma web desarrollada para el consultorio Dr. Katherine C Pediatrics, enfocada en mejorar su presencia digital y optimizar la gestión de citas médicas en línea.

El sistema integra un módulo de agendamiento inteligente, analítica de visitantes, integración con contenido de redes sociales y un chatbot de asistencia para consultas frecuentes.

La solución fue construida con una arquitectura web moderna, ligera y escalable, diseñada para ofrecer una experiencia clara para padres y tutores, mientras facilita la administración digital del consultorio.

Categoría: Desarrollo Web – Plataforma Médica. Web Estado: En desarrollo / implementación.

Rol: Arquitectura del sistema y desarrollo full-stack con integración de agenda médica, analítica web y redes sociales.

Enlaces: https://drkatherinecpediatrics.com/ Repositorio: Próximamente disponible.

CmLayerBank

Plataforma fintech conceptual enfocada en el desarrollo de soluciones bancarias digitales modernas, orientadas a simplificar la gestión financiera y explorar nuevas formas de interacción entre usuarios y servicios financieros.

El proyecto contempla la creación de una arquitectura escalable para servicios bancarios digitales, incluyendo módulos de gestión de cuentas, transacciones, analítica financiera y herramientas inteligentes orientadas a mejorar la experiencia del usuario.

La solución está diseñada bajo principios de arquitectura moderna, seguridad, escalabilidad e integración con tecnologías emergentes, como parte del ecosistema tecnológico de CmLayer.

Categoría: Desarrollo Fintech – Plataforma Bancaria Digital Web Estado: En planificación / desarrollo conceptual

Rol: Arquitectura del sistema, diseño de plataforma fintech y desarrollo de prototipo funcional.

Enlaces: https://www.cmlayerbank.com Repositorio: https://github.com/luiscdano/CmLayerBank
